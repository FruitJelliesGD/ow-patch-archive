# Overwatch 2 Retail Patch Notes - April 23, 2025

> 日期: 2025-04-23 · 站点: en · 来源: https://overwatch.blizzard.com/en-us/news/patch-notes/live/2025/04

## Hotfix Bug Fix Update

This is a hotfix for bugs recently discovered. Replay codes from the April 22, 2025 patch are still available.

## Bug Fixes

### Heroes

D.Va

- Fixed a bug where pilot D.Va could be invisible in Stadium.

Genji

- Fixed an issue where using Gloomgauntlet, Ambusher Optics or Hidden Blade did not increase Dragon Blade damage in Stadium.

Roadhog

- Fixed an issue with Take a Breather after using the Pent Up perk.

Sigma

- Fixed an issue with Sigma being able to hover correctly with the Levitation perk.

Zenyatta

- Fixed an issue with Zenyatta being able to hover correctly with the Ascendence perk.

### Missions

- Fixed an issue where the UI was unclear in the Resistance mission, making it difficult to progress through the mission.
