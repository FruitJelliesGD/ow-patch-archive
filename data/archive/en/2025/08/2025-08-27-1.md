# Overwatch 2 Retail Patch Notes - August 27, 2025

> 日期: 2025-08-27 · 站点: en · 来源: https://overwatch.blizzard.com/en-us/news/patch-notes/live/2025/08

## Hotfix Bug Fix Update

This is a hotfix for bugs recently discovered. Replay codes from the August 26, 2025 patch are still available.

## Bug Fixes

### General

- Resolved an issue where real-time text moderation was not working correctly.
- Resolved an issue where Universal Emotes could not be equipped.

### Heroes

Doomfist

- Resolved an issue where Doomfist Aftershock Perk not correctly applying slow if you land directly on top of enemies.

Echo

- Resolved an issue where Echo equipped with the Partial Scan perk was not gaining Ultimate Charge when duplicating D.Va.

Hazard

- Resolved an issue with Hazard’s infinite block when the Reconstitution Perk was equipped.

Sombra

- Resolved an issue where Sombra was able to gain overhealth from unhacked health packs.

Symmetra

- Resolved an issue where Symmetra’s teleporter was able to recover shield HP while being hacked.

Venture

- Resolved an issue where using SMART extender during Drill Dash would break the animation.

Wrecking Ball

- Resolved an issue with Wrecking Ball’s launch momentum.

Zarya

- Resolved an issue with Zarya’s Energy Converter Perk not granting charge for each enemy hit.
